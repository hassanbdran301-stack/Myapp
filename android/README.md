# تيليبرومبر (Android)

تطبيق يعرض السكربت في نافذة عائمة فوق كاميرا سامسونج أثناء تسجيل الفيديو.
النافذة تظهر على الشاشة فقط، والكاميرا لا تسجّلها.

- **ملف التثبيت:** `../dist/teleprompter.apk`
- **البناء من جديد:** `./build.sh` (يثبّت الأدوات الناقصة بنفسه، ولا يحتاج Gradle ولا Android Studio)

## الملفات
- `src/.../MainActivity.kt`: الشاشة الرئيسية (مربع النص مع حفظ تلقائي، زر «ابدأ»، شرح الصلاحية، فتح الكاميرا على وضع الفيديو)
- `src/.../OverlayService.kt`: النافذة العائمة (التمرير، الخط، السرعة، السحب، تغيير الارتفاع)
- `src/.../Prefs.kt`: القيم المحفوظة (السكربت، حجم الخط، السرعة، مكان النافذة)
